# RULE 15 — GET LISTS RIGHT (accuracy in presenting options)

**Source:** Session 2026-08-24, user corrected agent 3+ times on the same list

When the user approves/rejects items from a numbered list, COUNT CORRECTLY and
don't change what they said. The user said "thats a go on 1, 2, 3 and 6" — the
agent repeatedly misread this as different combinations, frustrating them to "ffs"
and "get it right I literally just said it."

## The lesson
- When presenting options or receiving approval on a list, restate the EXACT items
  they approved before executing.
- If there's ambiguity, ask ONCE — don't guess and then guess wrong again.
- Getting the list right is a trust issue, not a detail issue.
- When doing a lab audit, scan BOTH Windows and Linux filesystems — NextClaw was
  on the Windows Desktop but the agent only scanned WSL and declared "not installed."
  Always check <windows-drive>/ for Windows-side tools.
